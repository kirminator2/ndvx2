# Страницы объектов недвижимости

## Обзор

Реализована система отдельных страниц для каждого объекта недвижимости с детальной информацией.

## Функциональность

### 1. Кликабельные карточки объектов

- **Компонент**: `PropertyCard`
- **Функция**: При клике на карточку происходит переход на страницу объекта
- **Маршрут**: `/property/:id`

### 2. Детальная страница объекта

- **Компонент**: `PropertyDetail`
- **Функции**:
  - Полная информация об объекте
  - Галерея изображений
  - Характеристики недвижимости
  - Контактная информация
  - Аналогичные объекты
  - Добавление в избранное

## Компоненты

### PropertyCard

**Функции:**
- Отображение основной информации об объекте
- Клик для перехода на детальную страницу
- Кнопка добавления в избранное
- Рейтинг объекта
- Цена и площадь

**Пропсы:**
```typescript
interface PropertyCardProps {
  id?: number;
  title?: string;
  price?: string | number;
  image?: string;
  rating?: number;
  address?: string;
  total_area?: number;
  rooms_count?: number;
  floor?: number;
  total_floors?: number;
  construction_year?: number;
  // ... другие поля
}
```

### PropertyDetail

**Функции:**
- Полная информация об объекте
- Галерея изображений с каруселью
- Характеристики недвижимости
- Контактная информация
- Информация о ЖК
- Аналогичные объекты
- Кнопки действий (позвонить, в избранное)

**Структура страницы:**
1. **Заголовок и цена** - основная информация
2. **Галерея изображений** - карусель с фото
3. **Характеристики** - детальная информация
4. **Описание** - текстовое описание
5. **Аналогичные объекты** - похожие квартиры
6. **Боковая панель** - контакты, ЖК, карта

## Хуки

### usePropertyDetail

```typescript
const { data: property, isLoading, error } = usePropertyDetail(propertyId);
```

**Функции:**
- Загрузка детальной информации об объекте
- Кэширование на 10 минут
- Обработка ошибок
- Типизация данных

## Маршрутизация

### App.tsx

<Route path="/property/:id" element={<PropertyDetail />} />

## Оптимизация

### 1. Кэширование
- React Query кэширование на 10 минут
- Предзагрузка данных при наведении

### 2. Ленивая загрузка
- Изображения загружаются по мере необходимости
- Обработка ошибок загрузки изображений

### 3. SEO
- Уникальные URL для каждого объекта
- Метаданные для поисковых систем

## Дополнительные возможности

### 1. Аналогичные объекты
- Автоматический поиск похожих квартир
- Фильтрация по адресу и количеству комнат
- Ограничение до 5 объектов

### 2. Интеграция с ЖК
- Связь с Яндекс.Недвижимость
- Информация о жилом комплексе
- Рейтинги и отзывы

### 3. Контактная информация
- Телефон для связи
- Статус отправки в call-центр
- Кнопка "Позвонить"

## Использование

### Переход на страницу объекта

```typescript
// В компоненте PropertyCard
const handleCardClick = () => {
  if (id) {
    navigate(`/property/${id}`);
  }
};
```

### Получение данных объекта

```typescript
// В компоненте PropertyDetail
const { propertyId } = useParams();
const { data: property, isLoading, error } = usePropertyDetail(Number(propertyId));
```

### Добавление в избранное

```typescript
const toggleFavorite = () => {
  if (!property) return;
  
  if (isFavorite) {
    setFavorites(favorites.filter(fav => fav.id !== property.id));
  } else {
    const favoriteItem = {
      id: property.id,
      title: property.title,
      price: property.price.toString(),
      image: property.images?.[0] || "/placeholder.svg",
      rating: property.rating || 0,
      reviews: 0,
      tags: [],
      location: property.address
    };
    setFavorites([...favorites, favoriteItem]);
  }
};
```
