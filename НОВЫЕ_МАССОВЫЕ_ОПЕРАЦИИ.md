# Новые массовые операции

## Добавленные возможности

### 1. Создание slug'ов

#### Создать slug'и для адресов
- **Endpoint:** `POST /api/create-address-slugs`
- **Описание:** Создает уникальные slug'и для всех адресов, у которых их нет
- **Функция:** `createAddressSlugs()`
- **Результат:** Создано 10 slug'ов для адресов

#### Создать slug'и для ЖК
- **Endpoint:** `POST /api/generate-slugs`
- **Описание:** Создает уникальные slug'и для всех жилых комплексов
- **Функция:** `createComplexSlugs()`
- **Результат:** Создано X slug'ов для ЖК

#### Создать slug'и для связей Яндекс-ЖК
- **Endpoint:** `POST /api/create-yandex-link-slugs`
- **Описание:** Создает уникальные slug'и для всех связей с Яндекс-ЖК
- **Функция:** `createYandexLinkSlugs()`
- **Результат:** Создано 2251 slug'ов для связей

### 2. Обновление рейтингов

#### Обновить рейтинги Яндекс-ЖК
- **Endpoint:** `POST /api/update-yandex-ratings`
- **Описание:** Обновляет рейтинги объектов недвижимости для Яндекс-ЖК
- **Функция:** `updateYandexRatings()`
- **Результат:** Рейтинги успешно обновлены

### 3. Геокодирование

#### Геокодировать ЖК
- **Endpoint:** `POST /api/geocode-all-complexes`
- **Описание:** Геокодирует все жилые комплексы, у которых есть координаты, но нет адреса
- **Функция:** `geocodeAllComplexes()`
- **Результат:** Обработано X комплексов

#### Геокодировать Яндекс-ЖК
- **Endpoint:** `POST /api/yandex-geocode-region`
- **Описание:** Геокодирует адреса для Яндекс-ЖК по выбранному региону
- **Функция:** `showGeocodeRegionModal()` + `geocodeRegion()`
- **Особенности:** Модальное окно для выбора региона
- **Результат:** Обработано X адресов в регионе

#### Геокодировать TrendAgent
- **Endpoint:** `POST /api/geocode-all-trend-buildings`
- **Описание:** Геокодирует все здания TrendAgent
- **Функция:** `geocodeAllTrendBuildings()`
- **Результат:** Обработано X зданий

### 4. Импорт данных

#### Импорт TrendAgent
- **Endpoint:** `POST /api/import-trendagent`
- **Описание:** Импортирует данные из TrendAgent (новостройки)
- **Функция:** `importTrendAgent()`
- **Результат:** Данные успешно импортированы

#### Импорт Яндекс-ЖК (обновлено)
- **Endpoint:** `POST /api/import-yandex-newbuildings`
- **Описание:** Импортирует данные Яндекс-ЖК с сохранением существующих
- **Функция:** `importYandexNewbuildings()`
- **Результат:** Добавлено X, Обновлено Y записей

## Интерфейс

### Страница массовых операций
Все новые операции доступны на странице `/bulk-operations` в виде карточек с:
- Иконками для каждой операции
- Описанием функциональности
- Кнопками для запуска
- Индикаторами загрузки
- Уведомлениями о результатах

### Модальные окна
- **Выбор региона:** Для геокодирования Яндекс-ЖК по регионам
- Загружает список регионов из API
- Позволяет выбрать конкретный регион

### Уведомления
Все операции показывают:
- Успешные результаты с детальной статистикой
- Ошибки с описанием проблемы
- Индикаторы загрузки во время выполнения

## Автоматическое создание slug'ов

### Для новых адресов
При создании нового адреса автоматически:
1. Генерируется slug из полного адреса
2. Проверяется уникальность
3. При необходимости добавляется счетчик
4. Сохраняется в базе данных

### Для новых связей Яндекс-ЖК
При создании новых связей автоматически:
1. Создаются slug'и для новых связей
2. Используется название комплекса как основа
3. Обеспечивается уникальность

## API Endpoints

### Новые endpoints
- `POST /api/create-address-slugs` - Создать slug'и для адресов
- `POST /api/create-yandex-link-slugs` - Создать slug'и для связей Яндекс-ЖК

### Обновленные endpoints
- `POST /api/import-yandex-newbuildings` - Теперь возвращает статистику добавленных/обновленных записей
- `POST /api/update-yandex-links` - Теперь возвращает статистику новых/обновленных связей

## Преимущества

1. **Централизованное управление:** Все массовые операции в одном месте
2. **Удобный интерфейс:** Карточки с описанием и кнопками
3. **Детальная статистика:** Показывается количество обработанных записей
4. **Автоматизация:** Slug'и создаются автоматически
5. **Безопасность:** Данные не удаляются, только обновляются
6. **Обратная связь:** Уведомления о результатах операций

## Использование

1. Откройте страницу `/bulk-operations`
2. Выберите нужную операцию
3. Нажмите кнопку для запуска
4. Дождитесь завершения операции
5. Просмотрите результат в уведомлении

Все операции выполняются асинхронно и не блокируют интерфейс.
