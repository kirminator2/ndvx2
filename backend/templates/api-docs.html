Документация API

Здесь вы найдете описание доступных API-эндпоинтов для работы с данными недвижимости.

Основные эндпоинты объектов недвижимости

  • GET /api/properties — Получить список объектов недвижимости
  • GET /api/properties-fast — Быстрое получение объектов недвижимости
  • GET /api/properties-light — Облегченный список объектов
  • GET /api/property/<property_id> — Получить детальную информацию об объекте
  • GET /api/price-history/<property_id> — История изменения цен объекта
  • GET /api/property/<property_id>/last-price-change — Последнее изменение цены
  • GET /api/recent-price-changes — Недавние изменения цен
  • GET /api/price-statistics — Статистика цен
  • POST /api/generate-description/<property_id> — Сгенерировать описание объекта
  • POST /api/antiznak/<property_id> — Обработка через Антизнак

Жилые комплексы

  • GET /api/complexes — Получить список жилых комплексов
  • GET /api/complexes-light — Облегченный список ЖК
  • GET /api/complexes-with-properties — ЖК с объектами недвижимости
  • GET /api/complexes-with-slugs — ЖК со slug
  • GET /api/complex-slug/<complex_name> — Получить slug ЖК
  • GET /api/complex-properties/<complex_name> — Объекты в ЖК
  • GET /api/complex-properties-slug/<slug> — Объекты в ЖК по slug
  • GET /api/complex-info/<complex_name> — Информация о ЖК
  • GET /api/property/<property_id>/complex — ЖК для объекта
  • POST /api/import-complexes — Импортировать ЖК
  • POST /api/generate-slugs — Сгенерировать slug для ЖК
  • POST /api/link-properties-complexes — Связать объекты с ЖК

Адреса и геокодирование

  • GET /api/address-properties/<address_id> — Объекты по адресу
  • GET /api/address-properties-slug/<slug> — Объекты по slug адреса
  • GET /api/addresses-with-slugs — Адреса со slug
  • GET /api/address-slug/<address_id> — Получить slug адреса
  • POST /api/generate-address-slugs — Сгенерировать slug для адресов
  • POST /api/geocode-property/<property_id> — Геокодировать объект
  • POST /api/geocode-all — Геокодировать все объекты
  • POST /api/geocode-complex/<complex_id> — Геокодировать ЖК
  • POST /api/geocode-all-complexes — Геокодировать все ЖК

Яндекс-ЖК (новостройки)

  • GET /api/yandex-newbuildings — Получить список Яндекс-ЖК
  • GET /api/yandex-newbuildings/regions — Получить список регионов Яндекс-ЖК
  • GET /api/yandex-linked-complexes — Получить связанные Яндекс-ЖК
  • GET /api/link-properties-yandex — Получить связанные объекты и Яндекс-ЖК
  • POST /api/import-yandex-newbuildings — Импортировать Яндекс-ЖК
  • POST /api/update-yandex-links — Обновить связи Яндекс-ЖК
  • POST /api/create-yandex-link-slugs — Создать slug'и для связей Яндекс-ЖК
  • POST /api/create-address-slugs — Создать slug'и для адресов
  • POST /api/update-yandex-ratings — Обновить рейтинги Яндекс-ЖК
  • POST /api/yandex-geocode-region — Геокодировать адреса для региона
  • POST /api/yandex-geocode-one/<building_id> — Геокодировать один адрес

TrendAgent (новостройки)

  • GET /api/trend-buildings — Получить список зданий TrendAgent
  • POST /api/import-trendagent — Импортировать данные TrendAgent
  • POST /api/geocode-trend-building/<building_id> — Геокодировать здание TrendAgent
  • POST /api/geocode-all-trend-buildings — Геокодировать все здания TrendAgent

Фотографии и медиа

  • GET /api/complex-photos/<address_id> — Фотографии ЖК
  • POST /api/add-complex-photo — Добавить фото ЖК
  • POST /api/add-complex-photos-from-folder — Добавить фото из папки

Продавцы и контакты

  • GET /api/seller-contacts — Получить контакты продавцов
  • POST /api/import-seller-contacts — Импортировать контакты продавцов
  • POST /api/migrate-property-contacts — Мигрировать контакты объектов
  • POST /api/send-phone — Отправить номер телефона

Статистика и аналитика

  • GET /api/stats — Получить статистику
  • GET /api/stats-light — Облегченная статистика
  • POST /api/update-ratings — Обновить рейтинги

Автодополнение и поиск

  • GET /api/objects-autocomplete — Автодополнение объектов

Управление задачами

  • POST /api/stop-all-tasks — Остановить все задачи
  • POST /api/reset-stop-flag — Сбросить флаг остановки

Импорт и экспорт данных

  • GET /api/load-data — Загрузить данные
  • GET /api/download-and-update — Скачать и обновить данные
  • GET /export-properties-csv — Экспорт объектов в CSV

Примеры запросов

# Получить список объектов
curl http://127.0.0.1:5000/api/properties

# Получить объект по ID
curl http://127.0.0.1:5000/api/property/123

# Получить объекты по slug адреса
curl http://127.0.0.1:5000/api/address-properties-slug/g-krasnodar-ul-skandinavskaya-d-1-k-4

# Получить ЖК по slug
curl http://127.0.0.1:5000/api/complex-properties-slug/zhk-skandinaviya

# История цен объекта
curl http://127.0.0.1:5000/api/price-history/123
