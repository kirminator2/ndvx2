Документация API

Здесь вы найдете описание доступных API-эндпоинтов для работы с данными недвижимости.

Основные эндпоинты

  • GET /api/properties — Получить список объектов недвижимости
  • GET /api/complexes — Получить список жилых комплексов
  • GET /api/seller-contacts — Получить контакты продавцов
  • GET /api/stats — Получить статистику
  • POST /api/import-complexes — Импортировать ЖК
  • POST /api/import-seller-contacts — Импортировать контакты продавцов
  • POST /api/update-ratings — Обновить рейтинги
  • POST /api/geocode-all — Геокодировать все объекты
  • POST /api/geocode-all-complexes — Геокодировать все ЖК

Яндекс-ЖК (новостройки)

  • GET /api/yandex-newbuildings — Получить список Яндекс-ЖК
  • GET /api/yandex-newbuildings/regions — Получить список регионов Яндекс-ЖК
  • GET /api/yandex-linked-complexes — Получить связанные Яндекс-ЖК
  • POST /api/import-yandex-newbuildings — Импортировать Яндекс-ЖК
  • POST /api/update-yandex-links — Обновить связи Яндекс-ЖК
  • POST /api/update-yandex-ratings — Обновить рейтинги Яндекс-ЖК
  • POST /api/yandex-geocode-region — Геокодировать адреса для региона
  • POST /api/yandex-geocode-one/{building_id} — Геокодировать один адрес
  • GET /api/link-properties-yandex — Получить связанные объекты и Яндекс-ЖК

Полезные ссылки

  • /api/properties
  • /api/complexes
  • /api/seller-contacts
  • /api/stats

Ссылки Яндекс-ЖК

  • /api/yandex-newbuildings
  • /api/yandex-newbuildings/regions
  • /api/yandex-linked-complexes
  • /api/link-properties-yandex

Пример запроса

curl https://ваш_домен/api/properties

Для получения подробной информации по каждому эндпоинту обратитесь к разработчику или ознакомьтесь с исходным кодом backend/app.py.
